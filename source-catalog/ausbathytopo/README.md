# AusBathyTopo 250 m (`ausbathytopo`)

250 m bathymetry compilation for the Australian EEZ, zip on the AusSeabed file server. Attribute Geoscience Australia / AusSeabed, CC-BY 4.0. Elevations are approximately mean sea level, as published.

Run from `pipelines/` with `just ../source-catalog/ausbathytopo/`.
