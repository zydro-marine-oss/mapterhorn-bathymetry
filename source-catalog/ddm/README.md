# Danmarks Dybdemodel 50 m (`ddm`)

The 50 m Danish depth model is published at Dataforsyningen (dataset 4707). The public page did not expose a stable file URL (the download is a short-lived weblink). This source is not fetched until that URL is known. Do not substitute a third-party copy.

Run from `pipelines/` with `just ../source-catalog/ddm/`.
