# EMODnet Bathymetry DTM 2024 (`emodnet`)

European seas digital terrain model for 2024, about 1/16 arc-minute (~115 m), published as GeoTIFF tiles on the EMODnet download service. Vertical values are relative to lowest astronomical tide, as stated by EMODnet. Cite the EMODnet Bathymetry Consortium under CC-BY 4.0.

The tile names below are the files that answered on `downloads.emodnet-bathymetry.eu` for the 2024 grid.

Run from `pipelines/` with `just ../source-catalog/emodnet/`.
