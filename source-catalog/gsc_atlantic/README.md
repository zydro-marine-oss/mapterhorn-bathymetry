# GSC Atlantic 100 m (`gsc_atlantic`)

100 m GeoTIFF named on the Open Government record for the Scotian Shelf and Newfoundland-Labrador compilation (NRCan). The record also offers a file geodatabase; this list uses the GeoTIFF. The record does not give a single vertical datum. Open Government Licence – Canada.

Run from `pipelines/` with `just ../source-catalog/gsc_atlantic/`.
