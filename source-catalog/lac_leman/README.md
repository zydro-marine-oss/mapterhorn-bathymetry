# swissBATHY3D Lac Léman (`lac_leman`)

Lake Geneva bed elevations from swisstopo's swissBATHY3D, ESRI ASCII grid in EPSG:2056 (LN02 heights). The grid is orthometric elevation of the bed, not depth below the surface, and this catalog does not subtract a lake level. `domain` is `both`. Attribute swisstopo.

Run from `pipelines/` with `just ../source-catalog/lac_leman/`.
