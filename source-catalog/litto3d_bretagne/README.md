# Litto3D Bretagne (`litto3d_bretagne`)

Coastal lidar for Brittany, published by Shom and IGN. The diffusion page is the official access point. A stable anonymous list of the prepackaged archives was not available, and each archive holds more than one grid resolution, so this source is not fetched automatically. Cite Shom and IGN if you add the files later.

Run from `pipelines/` with `just ../source-catalog/litto3d_bretagne/`.
