# CCO multibeam bathymetry (`uk_cco`)

Nearshore multibeam for England and Wales is published by the Channel Coastal Observatory. Downloads go through a session and a basket on coastalmonitoring.org. There is no stable anonymous file URL, so this source is not fetched. Attribute the National Network of Regional Coastal Monitoring Programmes, and mark products as not for navigation.

Run from `pipelines/` with `just ../source-catalog/uk_cco/`.
