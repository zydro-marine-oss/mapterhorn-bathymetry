# DORIS Dorset seabed survey (`uk_cco_doris`)

1 m Dorset seabed grids are part of the same Channel Coastal Observatory basket as the other CCO surveys. No stable anonymous URL was found, so this source is not fetched. If the grids are added later, keep the DORIS attribution and a not-for-navigation notice.

Run from `pipelines/` with `just ../source-catalog/uk_cco_doris/`.
