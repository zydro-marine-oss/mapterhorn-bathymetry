# Coastal multibeam bathymetry (`uk_multibeam`)

Coastal multibeam surveys published as tiles on the Environment Agency survey service (`bathymetry_coastal_multibeam`). Heights are Ordnance Datum Newlyn. The file list is whatever that service returned along the English coast. Tile downloads did not require an API key.

Run from `pipelines/` with `just ../source-catalog/uk_multibeam/`.
