# SurfZone DEM 2019 (`uk_surfzone`)

2 m intertidal elevation model for England, Ordnance Datum Newlyn, from the Environment Agency survey-tile service. The file list is the `surfzone_dem_2019` tiles returned by that service for the English coast. Downloads from the tile URL succeeded without an API key.

Run from `pipelines/` with `just ../source-catalog/uk_surfzone/`.
