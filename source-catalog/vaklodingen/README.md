# Vaklodingen (`vaklodingen`)

20 m bathymetry and elevation for Dutch coastal waters, estuaries, and the main rivers, published by Rijkswaterstaat as one GeoTIFF. Heights are in NAP (Amsterdam Ordnance Datum), which is close to mean sea level. CC0.

Run from `pipelines/` with `just ../source-catalog/vaklodingen/`.
